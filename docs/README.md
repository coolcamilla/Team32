# Operation: EarthCore - Documentation

Welcome to the maintained documentation site for **Operation: EarthCore**, a 2D mining/exploration game where the player controls a mole digging toward Earth's Core.

Use the sidebar to navigate between the product, process, quality, testing, and architecture documentation. Every page here is the same maintained Markdown file that lives in the repository's `docs/` folder - this site exists purely to make them browsable, cross-linked and easy to read. The links to the scripts and other files outside the docs/ directory are unavailable, simply because this website is meant to represent only the docs/ directory. If you want to see the files, you can check out the full repository.
