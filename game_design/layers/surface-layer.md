# Surface Layer

The first game layer, which is located at a depth of 0 to 100 meters.

## Blocks

### Dirt

- 4 HP
- Spawns everywhere within the layer
- Can be dug using paws and tools better
- Table of drop-down resources

| Resource | Probability |
| -------- | ----------- |
| Stick    | 0,4         |
| Stone    | 0,2         |
| Nothing  | 0,4         |
### Clay

- 8 HP
- Spawns in 5 blocks from the clay deposit
- Can be dug using wooden shovel and tools better
- Table of drop-down resources

| Resource   | Probability |
| ---------- | ----------- |
| Clay piece | 0,7         |
| Nothing    | 0,3         |

## Deposits

### Clay Deposit

- 2-3 per layer
- Reserves of the deposit: 100-150 clay pieces
- Mining station: Installation with a Bucket

## Tools

### Paws

- The mole's paws, without any tools, have been there since the beginning of the game
- Recipe: none
- Can dig through: dirt
- Damage: 1 HP
### Wooden Shovel

- Sticks, neatly folded into the shape of a shovel
- Recipe: 12 sticks
- Can dig through: dirt, clay
- Damage: 2 HP
### Stone Shovel

- A stone on a stick
- Recipe: 10 sticks + 7 stones
- Can dig through: dirt, clay
- Damage: 4 HP
## Mining Stations

### Installation with a Bucket

- Assembled from ..., stones and sticks. It mines clay.
- Recipe: 10 sticks + 10 stones
- Extracts clay pieces
- Mining speed: 5 clay pieces/minute
